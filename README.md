# MEMAS (Next.js)

## التشغيل
1. `npm install`
2. انسخ `.env.example` إلى `.env` واملأه.
3. للتطوير: `npm run dev` ثم افتح `http://localhost:3000`.
4. للإنتاج: `npm run build` ثم `npm start`.
5. لوحة الأدمن: `/admin`.

## الإعدادات
- اسم المكان، الروابط، والرسالة اللي بتتبعت على واتساب: `lib/config.js`.
- الصور والتعليقات بتتحفظ في `DATA_DIR` (فولدر على قرص دائم، وخد منه نسخة احتياطية).
- الاستضافة لازم تكون Node.js بملفات دائمة (VPS أو Render أو Railway بـ Volume). منصات زي Vercel مش مناسبة لأن الصور بتتحفظ على الملفات.
